# Dolce Pharm LMS — обучение операторов без интернета

## Задача
Операторы цехов Dolce Pharm проходят инструктажи и СОП в местах, где почти нет интернета. Учёт ведётся в бумажных журналах, поэтому руководитель узнаёт о пропусках и просрочках с опозданием, а время обучения не подтверждено. Нужна лёгкая LMS, которая работает на телефоне без сети и сама доносит результаты до сервера.

## Данные
Все данные синтетические: 20 операторов, 3 курса, тесты, оценки 360 и история за 14 дней. При первом запуске их генерирует [backend/seed/seed.py](backend/seed/seed.py), документы и видео создаёт [generate_files.py](backend/seed/generate_files.py). Реальных персональных данных нет.

## Метод
- **PWA:** курс с PDF и видео сохраняется в IndexedDB и открывается в авиарежиме.
- **Очередь событий:** время по материалам и ответы попадают в локальный outbox с UUID. Сервер принимает их идемпотентно, дублей нет.
- **Синхронизация:** как только появляется сеть, данные уходят на сервер (требование — не дольше 20 с).
- **QR-передача:** без сети телефон показывает серию QR-кодов с подписью HMAC-SHA256, ноутбук мастера считывает их камерой.
- **Конвертация:** Word, Excel и PowerPoint превращаются в PDF (LibreOffice), видео сжимается до 720p (ffmpeg).
- **Оценка:** на телефоне — предварительная, по хэшам ответов. Итоговую сервер пересчитывает сам.

## Метрики до/после
«После» измерено сценарием [frontend/e2e/metrics.mjs](frontend/e2e/metrics.mjs) (Pixel 7, LAN), сырые данные — [docs/metrics.json](docs/metrics.json). «До» — оценка ручного процесса.

| Метрика | До (бумага, Excel) | После |
|---|---|---|
| Результат у руководителя после появления сети | 1–7 дней (оценка) | **0,8 с** (медиана 5 замеров), на сервере 0,2 с |
| Размер курса на телефоне | — | **0,2 МБ** (демо-курс: PDF, видео, текст) |
| Открытие без интернета | найти папку с инструкцией | **0,1 с** приложение, **0,1 с** PDF |
| Передача результата без сети | переписать вручную, ~3 мин (оценка) | **9 QR-кодов**, цикл карусели **9 с** |

## Ограничения
- **iOS:** нет фоновой синхронизации, данные уходят, пока приложение открыто. Квота хранилища меньше.
- **Туннель Cloudflare:** адрес меняется при каждом перезапуске.
- **Хэши ответов:** не криптостойкая защита, итог всегда считает сервер.
- **Загрузка через туннель:** не больше ~100 МБ за раз.

Подробнее и план снятия — [docs/LIMITATIONS.md](docs/LIMITATIONS.md).

## Запуск
```bash
./scripts/make-certs.sh       # HTTPS для localhost и LAN
docker compose up --build     # сервер + демо-данные → https://localhost
./scripts/tunnel.sh           # адрес для телефона из любой сети
```
Пароль у всех `demo123`:
- `op01`…`op20` — операторы;
- `methodist` — методист;
- `manager1`, `manager2` — начальники цехов;
- `admin` — администратор.
