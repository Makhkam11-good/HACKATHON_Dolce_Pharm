# Dolce Pharm LMS — обучение операторов без сети

Лёгкая LMS для фармацевтических цехов, где нет интернета:

- **Методист** собирает курс в веб-кабинете из обычных файлов. PDF, видео, Word, Excel и PowerPoint автоматически превращаются в PDF или видео 720p.
- **Оператор** скачивает курс на телефон (PWA), изучает материалы и сдаёт тест **в авиарежиме**. Время по каждому материалу учитывается честно: по монотонным часам, без учёта свёрнутого приложения и простоя.
- Каждое действие сначала пишется в локальную очередь и уходит на сервер, как только появляется сеть (на практике меньше чем за 1 с; требование кейса — 60 с).
- **Главная фишка:** если сети в цеху нет никогда, телефон передаёт результаты мастеру **серией QR-кодов с подписью HMAC-SHA256**. Подделать «сдал» нельзя, повтор не создаёт дублей, с телефона ничего не удаляется до подтверждения сервера.

> Демо-версия. Все данные синтетические и не содержат реальных персональных данных.

## Запуск

```bash
./scripts/make-certs.sh          # доверенный HTTPS (mkcert) для localhost и LAN IP — рекомендуется
docker compose up --build        # db + backend + nginx; первый запуск сам наполнит БД демо-данными
```

Откройте **https://localhost** (или `https://<LAN-IP>`). Если пропустить `make-certs.sh`, nginx создаст самоподписанный сертификат: на ноутбуке браузер покажет предупреждение, а на телефоне PWA, камера и WebCrypto работать не будут.

Публичный адрес для телефона из любой сети — `./scripts/tunnel.sh` (см. «Доступ с телефона с любой сети»).

Без Docker нужны только Python 3.12+, Node 20+ и PostgreSQL: `uvicorn app.main:app` в `backend/` и `npm run dev` в `frontend/` (прокси `/api` → `:8000`).

## Как открыть с телефона

Телефон и ноутбук должны быть в одной сети (Wi-Fi или точка доступа). LAN IP показывает `bash scripts/lan-ip.sh`.

1. Выполните `./scripts/make-certs.sh` и перезапустите nginx: `docker compose restart nginx`. Корневой сертификат появится в `nginx/certs/rootCA.pem`.
2. Перенесите `rootCA.pem` на телефон (почтой, через мессенджер или USB) и установите его:
   - **Android:** «Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС» → выбрать `rootCA.pem`.
   - **iOS:** открыть файл → «Настройки → Загружен профиль → Установить». Затем **«Настройки → Основные → Об этом устройстве → Доверие сертификатам»** → включить доверие для mkcert.
3. Откройте `https://<LAN-IP>` в Chrome (Android) или Safari (iOS).
4. Установите приложение: в Chrome — «⋮ → Установить приложение», в Safari — «Поделиться → На экран „Домой“». Иконка: «DP Обучение».
5. Войдите один раз при наличии сети. После этого приложение открывается и в авиарежиме.

## Доступ с телефона с любой сети

Если телефон не в одной сети с ноутбуком (мобильный интернет, другой Wi-Fi), используйте Cloudflare Tunnel. Он даёт временный публичный адрес с настоящим HTTPS, поэтому сертификаты на телефон ставить не нужно, а аккаунт Cloudflare не требуется.

```bash
./scripts/tunnel.sh
```

Скрипт поднимает весь стек вместе с сервисом `tunnel` (`docker compose --profile tunnel up -d`) и печатает адрес вида `https://<слова>.trycloudflare.com`. Если адрес потерялся, найдите его в логах: `docker compose --profile tunnel logs tunnel | grep trycloudflare`.

1. Откройте адрес на телефоне в Chrome (Android) или Safari (iOS) и войдите.
2. Установите PWA («Установить приложение» / «На экран „Домой“») и скачайте курсы для офлайна.
3. Синхронизация идёт через тот же адрес из любой сети.

> **Адрес меняется при каждом перезапуске туннеля** (`docker compose restart`, перезагрузка ПК, `tunnel.sh`). Для телефона это новый сайт: PWA, вход и скачанные курсы привязаны к старому адресу. Тогда **установите PWA заново по новому адресу и заново скачайте курсы**. Перед перезапуском туннеля дождитесь «Всё отправлено» в шапке, иначе неотправленные результаты останутся в старом PWA. Если они всё же остались, передайте их через «Передать без сети» (QR).

- Остановить туннель: `docker compose stop tunnel`. Сам сервер продолжит работать по `https://localhost` и в LAN.
- Через туннель один запрос ограничен **~100 МБ**. Файлы курсов больше 95 МБ загружайте с компьютера сервера через `https://localhost`: кабинет методиста подскажет это при выборе такого файла.
- Абсолютные ссылки (QR проверки в PDF сертификата) строятся из `PUBLIC_BASE_URL` в `.env`. Если переменная пуста, адрес берётся из запроса (`X-Forwarded-Host` / `X-Forwarded-Proto`), поэтому QR указывает на тот адрес, с которого скачали PDF.
- Quick Tunnel — бесплатный сервис без гарантий доступности, он подходит для демо. Для постоянного адреса нужен именованный туннель Cloudflare со своим доменом. Укажите этот домен в `PUBLIC_BASE_URL`.

## Демо-логины (пароль у всех `demo123`)

| Логин | Роль |
|---|---|
| `op01` … `op20` | сотрудники-операторы (у `op01`, `op02` чистая история — удобно для демо) |
| `methodist` | методист (Баймуханова С. Е.) |
| `manager1` | начальник цеха твёрдых лекарственных форм |
| `manager2` | начальник цеха стерильных растворов |
| `admin` | администратор |

## Проверка офлайна и QR за 3 минуты

1. Телефон, `op01`: «Мои курсы» → «Действия при разливе…» → **Скачать офлайн**.
2. **Авиарежим.** Откройте презентацию (это PDF из PPTX) и текстовый блок, затем пройдите тест. В вопросе на порядок перетаскивайте пальцем. На экране результата: «Предварительный результат…», в шапке: «Офлайн · N не отправлено».
3. **Вариант А:** выключите авиарежим. В шапке появится «Всё отправлено». На ноутбуке (`methodist` → «Отчёты») будут время по материалам, статус и задержка синхронизации.
4. **Вариант Б:** не выключая авиарежим, откройте «Ещё → Передать без сети → Показать QR-коды». На ноутбуке войдите как `manager1` → «Принять по QR» → поднесите телефон к камере → «Принято: …». Кнопка «Демо: отправить изменённый пакет» покажет «Подпись не совпала».

Подробный сценарий выступления — [docs/demo-script.md](docs/demo-script.md).

## Соответствие критериям кейса

| Требование | Где реализовано |
|---|---|
| Офлайн и синхронизация (20) | PWA + Service Worker ([frontend/src/sw.ts](frontend/src/sw.ts)), пакет курса в IndexedDB ([downloader.ts](frontend/src/offline/downloader.ts)), outbox → `/api/sync` с повтором и экспоненциальной паузой ([syncEngine.ts](frontend/src/offline/syncEngine.ts)), идемпотентность `ON CONFLICT DO NOTHING` ([sync_service.py](backend/app/services/sync_service.py)), QR-канал ([qrExport.ts](frontend/src/offline/qrExport.ts), [qr_service.py](backend/app/services/qr_service.py)) |
| Учёт времени (15) | Интервалы по `performance.now()`, пауза при сворачивании и после 120 с простоя, чекпойнт каждые 30 с, восстановление после выгрузки страницы ([timeTracker.ts](frontend/src/offline/timeTracker.ts)). Поправка на часы телефона на сервере. Отчёты «Вход и выход», «Время по материалам», «Синхронизация» |
| Курсы (10) | Конструктор, загрузка до 300 МБ, LibreOffice → PDF, ffmpeg → 720p, drag-and-drop порядка, версии публикации ([CourseEditor.tsx](frontend/src/pages/methodist/CourseEditor.tsx), [convert.py](backend/app/services/convert.py)) |
| Тесты, 4 типа (10) | single, multi, order (drag-and-drop), open (ключевые слова + ручная проверка). Одинаковая оценка на телефоне и сервере ([grading.ts](frontend/src/offline/grading.ts) ↔ [grading.py](backend/app/services/grading.py), общие кейсы [grading_cases.json](backend/tests/grading_cases.json)). Правильные ответы на телефоне только в виде хэшей |
| Библиотека (5) | Категории в 2 уровня, теги, поиск: онлайн — на сервере, офлайн — Fuse.js; «Сохранить офлайн» |
| Оценка 180/360 (8) | Запуск, формы работают офлайн, роза компетенций (Chart.js radar), разрывы, рекомендации курсов с кнопкой «Назначить» |
| Тренажёр (7) | Граф-сценарий, SVG-персонаж с 5 эмоциями, фоны, редактор узлов, загрузка JSON, офлайн |
| Роли и аттестация (5) | 4 роли (`require_role` + меню), сертификаты PDF с QR и публичной проверкой `/verify/<код>`, протокол аттестации PDF |
| Стабильность, авиарежим (10) | pytest: 24 теста; vitest: 30; сквозной API-тест: 44 проверки; браузерный E2E «авиарежим → сеть → QR → подделка → повтор»: 18 проверок |
| Удобство для оператора (10) | Крупные зоны нажатия ≥ 48 px, нижняя навигация, один вопрос на экран, индикатор сети и синхронизации в шапке, казахский язык |

Отчёты выгружаются в XLSX и CSV (UTF-8 с BOM, разделитель `;` — без проблем открываются в Excel). С телефона отчёты 1–3 выгружаются **из локальных данных, без сети**.

## Тесты

```bash
docker compose exec backend python -m pytest -q          # оценка, идемпотентность sync, смещение часов, QR (подпись/подделка/повтор/компакция)
docker compose exec backend python tests/smoke_api.py    # сквозная проверка API на демо-данных
cd frontend && npm test                                  # vitest: grading.ts и answerHash на общих кейсах, упаковка ↔ распаковка QR
cd frontend && npm i --no-save playwright-core && node e2e/offline-flow.mjs   # браузерный E2E (нужен Chrome или Edge)
```

## Архитектура

```
[Телефон: PWA] UI · Service Worker (оболочка) · IndexedDB (курсы, Blob-файлы, outbox)
   ├─ timeTracker → outbox ─┬─ syncEngine → HTTPS → nginx → FastAPI → PostgreSQL
   │                        └─ qrExport → QR-карусель → камера мастера → POST /api/sync/qr
```

- Стек: FastAPI, SQLAlchemy 2, PostgreSQL 16, React 18, Vite, Tailwind, Dexie, Workbox, pdf.js, Chart.js. Внешних CDN и облаков нет, всё работает в локальной сети.
- Документация API: `https://<host>/api/docs` (Swagger), кратко — [docs/api.md](docs/api.md).
- Решения в местах, где ТЗ допускает трактовку: [docs/decisions.md](docs/decisions.md).

## Известные ограничения

- **iOS:** нет Background Sync — синхронизация идёт, пока приложение открыто. Квота хранилища меньше. Установите PWA на экран «Домой», иначе Safari может удалить данные через 7 дней неактивности.
- Сложные PPTX (анимации, встроенное видео) превращаются в статичный PDF.
- Хэши правильных ответов защищают только от «подсмотреть в IndexedDB», а не от решительного взломщика. Итоговая оценка всегда серверная (подробнее — в [docs/decisions.md](docs/decisions.md)).
- Все данные синтетические. Для реальной эксплуатации смените `JWT_SECRET` в `.env` (см. `.env.example`).
