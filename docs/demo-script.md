# Сценарий демо: видео 90 секунд и питч 3 минуты

Цифры взяты из замера [`frontend/e2e/metrics.mjs`](../frontend/e2e/metrics.mjs), данные — [metrics.json](metrics.json).

## Подготовка (за 10 минут)

1. На ноутбуке выполнить `bash scripts/start.sh` (или запустить `start.cmd`). Открыть `https://localhost`: вкладка 1 — вход `methodist`, вкладка 2 — `manager1` → «Принять результаты сотрудников» → «Включить камеру» → «Разрешить».
2. Телефон: приложение установлено по адресу туннеля на экран «Домой», вход `op01`, яркость на максимум, авиарежим выключен.
3. На рабочем столе ноутбука — `СОП переодевание.docx` (демо-файлы: `docker compose cp backend:/app/storage/seed_src ./demo-files`).
4. Для записи видео: экран телефона (зеркалирование или запись экрана) и экран ноутбука, звук — голос за кадром.
