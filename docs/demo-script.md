# Сценарий демо для жюри (5–7 минут)

**Подготовка (за 10 минут до выступления):**

1. Ноутбук, на котором запущен `docker compose up`: открыть `https://<LAN-IP>` и войти как `methodist`. Во второй вкладке войти как `manager1` и открыть «Принять по QR», чтобы разрешить доступ к камере.
2. Телефон: корневой сертификат mkcert установлен, приложение установлено на экран (см. README). Войти как `op01`. Яркость экрана — на максимум.
3. Подготовить на рабочем столе ноутбука файлы для загрузки: `СОП переодевание в чистой зоне.docx` и любой MP4. Демо-файлы лежат в томе `storage/seed_src`, их можно скопировать командой `docker compose cp backend:/app/storage/seed_src ./demo-files`.

---

## 1. Методист собирает курс (1,5 мин) — ноутбук

1. «Курсы» → «Новый курс» → «Охрана труда: демо».
2. «Файл» → загрузить DOCX. Статус «конвертация…» на глазах меняется на «PDF готов», обычно за 5–15 с.
3. «Файл» → загрузить MP4. Статус «сжато до 720p».
4. «Тест» → добавить 4 типа вопросов: один ответ, несколько, порядок (варианты в правильном порядке), открытый (ключевые слова «остановить, мастер», минимум 1). Показать «Превью глазами сотрудника». «Сохранить тест».
5. «Опубликовать» → «Назначить» → отметить «Ахметов Нурлан» (op01) → «Назначить выбранным».

## 2. Оператор скачивает курс (30 с) — телефон

1. Открыть «Мои курсы» (список обновляется с сервера при открытии) — появляется новый курс.
2. «Скачать офлайн» → прогресс → бейдж «Доступен офлайн».

## 3. Авиарежим (1,5 мин) — телефон

1. **Включить авиарежим.** Шапка: «Офлайн», баннер «Нет сети — вы можете продолжать обучение».
2. Открыть PDF (листание, масштаб), затем видео (играет). Таймер материала тикает.
3. «Пройти тест»: в вопросе на порядок перетащить пальцем, в открытом ввести «остановлю и скажу мастеру».
4. Результат: «Предварительный результат: 100% — сдано. Итог подтвердится при синхронизации». Шапка: «Офлайн · N не отправлено».

## 4А. Сеть появилась (30 с)

1. Выключить авиарежим. Через 2–10 секунд шапка показывает «Всё отправлено · 14:32».
2. На ноутбуке открыть «Отчёты» → «Время по материалам» (обновляется каждые 5 с) — время совпадает с реальным.
3. Вкладка «Синхронизация»: колонка «Задержка после появления сети» — несколько секунд, «≤ 60 с ✓».
4. «Аттестация» — статус «сдал», номер сертификата.

## 4Б. Сети нет никогда (1,5 мин)

1. Телефон в авиарежиме: пройти ещё один материал (например, курс «Действия при разливе»).
2. «Ещё» → «Передать без сети» → «Показать QR-коды» → карусель «Код 1 из 3».
3. На ноутбуке («Принять по QR», manager1) поднести телефон к камере. Ячейки заполняются: «Собрано 3 из 3». Появляется «Принято: 37 событий, 1 попытка теста (Ахметов Н. — … — сдал, 90%)».
4. **Попытка подделки:** нажать «Демо: отправить изменённый пакет». Результат: «Подпись не совпала — пакет изменён или подделан».
5. Повторно показать те же коды: «Пакет уже был принят ранее», дублей нет.
6. Бонус: на телефоне «Сканировать подтверждение» → навести на QR-подтверждение на экране мастера → «Сервер подтвердил приём».
7. В «Отчётах» у этих событий источник «QR».

## 5. Выгрузки и сертификат (1 мин)

1. Ноутбук: «Отчёты» → «Excel». Файл открывается в Excel, кириллица в порядке.
2. Телефон (можно в авиарежиме): «Результаты» → «XLSX» — выгрузка из локальных данных.
3. «Результаты» → «Сертификат PDF». В PDF есть QR. Отсканировать QR камерой телефона → страница «Сертификат действителен».

## 6. Коротко о дополнительном (1 мин)

- **Оценка 360:** manager1 → «Оценка 360» → профиль Сидорова. Роза компетенций, таблица разрывов (подсвечено «Действия в нештатных ситуациях»), рекомендованный курс и кнопка «Назначить».
- **Тренажёр:** op01 → «Тренажёр» → «Разлив химического вещества». Мастер Айгерим меняет эмоции, в концовке «тревога» мигает красный фон.
- **Дашборд руководителя:** матрица «сотрудники × курсы», просрочки, протокол аттестации в PDF.

**Главная мысль для жюри:** подпись не даёт нарисовать поддельный «сдал». Идемпотентность не даёт задвоить данные при повторе через QR или сеть. С телефона ничего не удаляется, пока сервер не подтвердил приём.
