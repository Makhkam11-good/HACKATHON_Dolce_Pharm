## Контраст (текущая тема)

- `text-slate-400` (#94A3B8) на белом — 2.6:1 ✗ (подписи, неактивные элементы).
- Белый на `emerald-500` (#10B981) — 2.5:1 ✗ (ячейки «сдал» на дашборде).
- Светлые обводки кнопок `brand-300` — элементы плохо видны на солнце.

## Цвета бренда

Из CSS сайта (глобальные цвета Elementor): primary `#4F007D`, accent `#6839CC`, highlight `#E56D6D`, текст `#666666`, границы `#E5E5E5`.
Замер логотипа: фиолетовый ≈ `#48007A`, красный крест ≈ `#D0281A`. Синяя «D» (иконка вкладки сайта) — стоковая, в приложении не используется.
Статусы из брифа подправлены до AA: успех `#1F8A4C` → `#1B7D45` (4.4 → 5.2:1), предупреждение `#B26A00` → `#9A5B00` (4.2 → 5.4:1).
