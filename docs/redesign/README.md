# Редизайн Dolce Pharm LMS

Новый интерфейс сделан в фирменном стиле Dolce Pharm. Он рассчитан на операторов цеха, которые плохо разбираются в технологиях: простота важнее красоты. Функциональность (маршруты, роли, API, работа без интернета, учёт времени, QR, тесты) не менялась, менялись только интерфейс и тексты.

- Аудит до редизайна: [audit.md](audit.md).
- Согласованный макет: [mockup/brand-board.png](mockup/brand-board.png).
- Скриншоты: [before/](before/) и [after/](after/). Устройства: iPhone 14, Pixel 7, десктоп 1440. Снимаются командой `frontend/e2e/redesign-shots.mjs before|after`.

## Фирменный стиль

| Роль | Цвет | Где | Контраст с белым |
|---|---|---|---|
| Primary | `#4F007D` | шапка, главные кнопки, активный пункт меню, прогресс | 12,9:1 |
| Accent | `#6839CC` | подсказки, вторичные акценты, «информация» | 6,9:1 |
| Coral | `#E56D6D` | только декор: иллюстрации, линия «руководитель» на розе компетенций | 3,1:1, для текста не используется |
| Текст / подписи | `#2B2730` / `#5C5566` | основной текст / второстепенный | 14,6 / 7,1:1 |
| Фон / границы | `#F7F5F9` / `#E5E2E9` | | |
| Сдан | `#1B7D45` | | 5,2:1 |
| Срок прошёл / проверка | `#9A5B00` | | 5,4:1 |
| Не сдан / ошибка | `#C62828` | | 5,6:1 |
| Не начат | `#555555` | | 7,5:1 |

- **Откуда цвета.** Это глобальные цвета темы сайта dolcepharm.kz (`--e-global-color-primary` и другие). Фиолетовый совпадает с логотипом: замер по пикселям даёт около `#48007A`. Синяя «D» из иконки вкладки сайта — стоковая картинка, в приложении она не используется.
- **Статусы** взяты не из бренда, а из понятных всем цветов. Они всегда показываются вместе с иконкой и текстом: «Сдан ✓», «Не сдан — можно пересдать», «Ответ проверяет методист», «Не начат» (пунктирный круг). Цвета `#1F8A4C` и `#B26A00` из брифа я затемнил до AA.
- **Шрифт** — Inter, как на сайте. Подключён локально (`@fontsource/inter`, наборы latin + cyrillic + cyrillic-ext с казахскими буквами) и сохраняется на телефоне вместе с приложением.
- **Логотип и иконки** лежат в `frontend/public/brand/`: шапка на светлом и на тёмном фоне (на белой плашке), иконки 192 и 512, maskable, favicon, apple-touch, splash. Источники описаны в `docs/brand/source/SOURCES.md`.

## Дизайн-система

- **Токены.** Заданы в `frontend/tailwind.config.js` и CSS-переменных (`frontend/src/index.css`): цвета, отступы 4/8/12/16/24/32, скругления (кнопки 18 px, карточки 16 px), тени. Шкала `slate` и статусные `emerald` / `red` / `amber` переопределены так, что любой оттенок, который используется для текста, проходит AA.
- **Размеры.** На телефоне базовый шрифт 18 px (`html { font-size: 112.5% }`), на ПК 16 px. Межстрочный интервал 1,5.
- **Компоненты** (`frontend/src/components/ui.tsx`): Button (primary / secondary / danger / ghost / success, обычная и большая), Card, BigActionCard, ListItem, StatusBadge, ProgressBar, EmptyState, Banner (info / success / warn / error / offline), Modal, ConfirmModal, Toast, поля формы. Ещё есть TopBar, BottomNav, SideNav и «Ещё» в `Layout.tsx`, а также Onboarding.
- **Иконки** — набор в стиле Feather/Lucide (MIT/ISC), бандлится в приложение. Иконка всегда идёт с подписью.

## Что изменилось и почему

**Оператор (телефон):**
- **Главная.** Вместо одинаковых карточек теперь одна большая «Продолжить обучение» с одной кнопкой: «Сохранить на телефон», «Начать», «Продолжить» или «Перейти к тесту». Ниже короткий список остальных курсов с процентом, статусом и сроком.
- **Нижнее меню** — 4 пункта с подписями: Обучение, Результаты, Документы, Ещё. Выход и язык перенесены в «Ещё», с подписями и подтверждением, раньше кнопку выхода с одной иконкой легко было нажать случайно.
- **Простые слова.** «Скачать офлайн» → «Сохранить на телефон»; «Доступен офлайн» → «Сохранено на телефоне»; «синхронизация» → «Отправлено / Ждёт отправки: N»; «Передать без сети» / «QR» → «Передать результаты мастеру»; «Попытка 1 из 3» → «Осталось попыток: 2»; «На проверке» → «Ответ проверяет методист». Ошибки написаны человеческим языком: что случилось и что делать.
- **Курс:** «Материал 2 из 4», полоса прогресса, одна кнопка «Продолжить». Вместо «Минимум 1 мин 0 с · изучено 0 с» теперь «Изучите не меньше 1 мин».
- **Тест.** Вверху «Вопрос 3 из 10» и полоса, сетка мелких номеров убрана под «Все вопросы». Варианты ответа — карточки на всю ширину с галочкой. Для множественного выбора подсказка «Можно выбрать несколько», для вопроса на порядок — кнопки «Выше» и «Ниже» (перетаскивание осталось дополнительным способом). Перед завершением окно «Завершить тест? Изменить ответы будет нельзя» с двумя большими кнопками. На результате одна главная кнопка: «На главную» или «Пересдать тест».
- **Без интернета** — спокойная фиолетовая плашка «Нет интернета — можно продолжать учиться», не красная.
- **Знакомство при первом входе:** 3 экрана с иллюстрациями в стиле бренда и кнопкой «Пропустить».
- **Вход:** логотип, крупные поля, «Показать пароль», ошибка «Неверный логин или пароль», заметный выбор языка. Демо-входы спрятаны под отдельную кнопку.

**Мастер:**
- Главная называется «Кто не прошёл обучение». Сверху итоги, ниже карточки людей, которым нужно внимание (просрочки сверху), у каждого статус цветом, иконкой и текстом. Таблица «сотрудники × курсы» осталась только на ПК, с контрастными цветами. Раньше было 2,5:1, белым по ярко-зелёному.
- На телефоне крупная кнопка «Принять результаты сотрудников». На экране приёма понятная инструкция, «Собрано 3 из 9» и крупный итог «Принято: Иванов А. — Охрана труда — сдал, 90%».

**Методист и ПК:**
- Боковое меню закреплено, у каждого пункта иконка и подпись, внизу выбор языка и «Выйти».
- Отчёты: сначала крупные итоги (назначено / сдано / не сдано / просрочено), потом вкладки, фильтры, таблица и кнопки «Скачать Excel» / «Скачать CSV».
- Редактор курса по шагам: «1. Описание → 2. Материалы → 3. Тест → 4. Назначение».
- Пустые состояния с подсказкой: «Курсов пока нет — нажмите «Создать курс»».
- Роза компетенций 180/360 в цветах бренда. Серии различаются не только цветом, но и линией (сплошная / штрих / точки) и формой точек (круг / квадрат / треугольник).

## Тест «5 секунд»: что пришлось упростить

| Экран | Было непонятно | Стало |
|---|---|---|
| Главная | все курсы одинаковые, у каждого «Скачать офлайн» | одна карточка с одной кнопкой: что нажать — очевидно |
| Курс | надо самому выбрать материал | «Продолжить» сразу открывает следующий неизученный материал |
| Курс (сданный) | «Сдан» и рядом «0% · Начать» | «Курс пройден · 100%», без лишней кнопки |
| Материал | счётчик «3 с / 1 мин 0 с» в тревожной плашке | спокойная полоса «Изучите не меньше 1 мин» → «Изучено — можно идти дальше» |
| Последний материал | «К тесту» вело на страницу курса | «Перейти к тесту» сразу открывает тест, если всё изучено |
| Тест | сетка номеров 1–10 отвлекает; «Выберите все верные» мелко серым | «Вопрос 3 из 10», крупная подсказка фиолетовым |
| Вопрос на порядок | маленькие стрелки без подписи | кнопки «Выше» и «Ниже» с подписью |
| Завершение теста | системное окно браузера | своё окно с двумя большими кнопками и числом вопросов без ответа |
| Результат | «Предварительный результат. Итог подтвердится при синхронизации» | «Тест сдан!» / «Тест не сдан — можно пересдать», одна кнопка |
| Передача мастеру | «Пакет 3au55oyf: событий 4»; главная кнопка неактивна без пояснения | «Ждут отправки: 4», «Показать коды мастеру», «Всё уже отправлено» |
| Шапка | выход — иконка рядом с языком | в шапке только логотип и «Всё отправлено / Ждёт отправки: N» |

## Проверки

- `frontend/e2e/ux-checks.mjs`, все 140 проверок пройдены:
  - на iPhone 14, Pixel 7 и Android 360 px все кнопки, ссылки и поля не меньше 48×48 px и не перекрыты (`elementFromPoint` в центре);
  - на 360 px нет горизонтальной прокрутки;
  - контраст AA (axe-core, `color-contrast`) на всех экранах телефона и ПК.
- В `ru.json` и `kk.json` нет слов «синхронизация», «офлайн», «outbox», «PWA», «кэш». Все строки интерфейса переведены на казахский.
- Функциональность: `offline-flow.mjs` (авиарежим → сеть → передача мастеру → подделка → повтор) — 18 из 18; `mobile-qr.mjs` — без провалов; vitest — 36; pytest — 27.
